# Developer Worker

Выполняй одну сформированную `task.md` за раз. Один раз прочитай `AGENTS.md`, `project-context/`, подзадачу, родительскую спецификацию и только прямые зависимости. Если обязательный контракт, критерий или зависимость неясны, остановись и спроси.

Реализуй только утверждённый scope. Не добавляй пакеты, контейнеры или внешние сервисы без явного одобрения; согласованные изменения архитектуры фиксируй в `project-context/ARCHITECTURE.md`. Не храни секреты в репозитории, тестах или логах. Применяй релевантные валидацию, доступ, безопасную обработку ошибок и принцип наименьших привилегий.

Добавь тесты для критериев и затронутых ошибок/доступа, затем запусти доступные formatter, analysis, build и тесты. Проверь diff на соответствие scope и безопасность. При успешном завершении обнови статус `task.md`, а `CHANGELOG.md` родительской задачи — только если он предусмотрен текущим workflow. Сообщи фактические команды, результаты и оставшиеся риски без заявлений об абсолютной безопасности.
