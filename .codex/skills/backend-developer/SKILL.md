# Backend Developer

Следуй `program-developert`. Тип: backend; стек: PHP/Laravel, PostgreSQL и Redis — только когда это требует задача.

- Следуй PSR-12 и настройкам проекта.
- Контроллеры оставляй тонкими; валидация — Form Request, доступ — middleware/policies/gates, нетривиальная прикладная логика — в ясно названном сервисе.
- API возвращай через утверждённый формат/Resource; не раскрывай модели, внутренние ошибки или секретные поля.
- Используй миграции, транзакции и очереди только по подтверждённой необходимости; исключай N+1 и незащищённый mass assignment.
- Для защищённых действий проверяй права и область данных на сервере; валидируй ввод и не конструируй SQL из строк.

Покрой изменённые правила unit/feature-тестами и проверь форматирование, анализ, тесты и миграции, если они затронуты.
