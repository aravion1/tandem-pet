# ID задачи: TASK-003

## Название задачи

Vue-интерфейс доступа и управления пользователями/ролями.

## Исполнитель

Frontend

## Полное описание

Создать mobile-first маршруты и экраны активации, входа, восстановления пароля, импорта жителей, смены телефона, просмотра и редактирования ролей/прав. Добавить единый механизм скрытия запрещённых действий.

## Контракты данных

Используются ответы TASK-002: текущий пользователь `{id, roles, permissions}`, роль `{id,name,permissions:[code]}` и ошибки 401/403/422. Пароль и SMS-код хранятся только в состоянии формы до отправки.

## Эндпоинты

Потребляются все эндпоинты TASK-002. Новые не создаются.

## Бизнес-логика

Не показывать управление пользователями/ролями без соответствующих прав. После подтверждения активации направлять в авторизованную область. Ошибки должны быть понятны, но не раскрывать наличие номера при восстановлении.

## Зависимости

TASK-002: API и контракт авторизации.

## Критерии готовности

На мобильной ширине доступны все формы; UI-тесты покрывают активацию, вход, скрытие управления ролями и отображение ошибок API.
