# ID задачи: TASK-000

## Название задачи

Bootstrap Laravel-приложения.

## Исполнитель

Backend

## Полное описание

Создать базовое Laravel-приложение в корне репозитория с зависимостью `laravel/framework` версии `^13.0` и требованием PHP 8.5. Подготовить минимальные `Dockerfile` и `compose.yaml`, чтобы Composer, Artisan и тесты запускались в Docker-контейнере PHP 8.5. Подготовить стандартную структуру Laravel, `artisan`, Composer-конфигурацию, `.env.example` без секретов и базовую конфигурацию подключения PostgreSQL через переменные окружения. Не создавать бизнес-модули, API, Redis, Docker-инфраструктуру для production или дополнительные сторонние зависимости.

## Контракты данных

Не затрагиваются. Должна быть доступна стандартная конфигурация Laravel `pgsql` через `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`.

## Эндпоинты

Не затрагиваются.

## Бизнес-логика

Не затрагивается. Каркас должен позволять следующим задачам создавать Laravel-миграции и тесты.

## Зависимости

Нет.

## Критерии готовности

- `composer.json` требует PHP 8.5 и Laravel `^13.0`;
- `docker compose run --rm app php artisan --version` успешно выполняется;
- `.env.example` не содержит секретов и определяет параметры PostgreSQL;
- `php artisan migrate:status` доступна после настройки тестового окружения;
- базовый тестовый набор Laravel запускается через Docker.
