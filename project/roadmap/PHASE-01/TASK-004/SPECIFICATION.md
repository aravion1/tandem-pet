# ID задачи: TASK-004

## Название задачи

Платформенная конфигурация: Docker, Redis, файлы и защита секретов.

## Исполнитель

Backend

## Полное описание

Подготовить конфигурацию монолита Laravel/Vue в Docker, подключение PostgreSQL и Redis, очереди, защищённое конфигурирование ключей шифрования и абстрактное файловое хранилище для будущих вложений. Добавить документированную процедуру резервного копирования и восстановления БД.

## Контракты данных

Конфигурация окружения содержит только ссылки на секреты; вложение в дальнейшем описывается как `{id, storage_key, original_name, mime_type, byte_size, created_at}`. Используется приватный локальный Docker volume; размер и квоты не ограничены по подтверждённому решению, исполняемые файлы запрещены.

## Эндпоинты

Не добавляются.

## Бизнес-логика

Очередь обязательна для отложенных уведомлений. Секреты, ключи шифрования и учётные данные не попадают в репозиторий. Хранилище принимает файлы любых форматов и размеров, как зафиксировано в ТЗ.

## Зависимости

TASK-001 для подключения БД; TASK-002 использует шифрование номера.

## Критерии готовности

`docker compose` поднимает Laravel, Vue, PostgreSQL и Redis; очередь обрабатывает тестовую задачу; резервная копия восстанавливается в чистую БД; секреты исключены из контроля версий.
