# ID задачи: TASK-012

## Название задачи

API аналитики и экспорт Excel.

## Исполнитель

Backend

## Полное описание

Реализовать расчёт утверждённых показателей за период и формирование Excel-выгрузки с соблюдением раздельных прав на аналитику и финансовые данные.

## Контракты данных

Ответ `AnalyticsReport {period:{from,to}, requests_by_status, tasks_by_status, completed_tasks_count, processed_requests_count, time:{total,items[]}, budget:{total,items[]|null}}`. Элемент детализации содержит `work_item_id,title,value`. При отсутствии `budget.view` поле `budget` равно `null` и не включается в Excel.

## Эндпоинты

`GET /api/analytics?from=YYYY-MM-DD&to=YYYY-MM-DD` требует `analytics.view`; `GET /api/analytics/export?from=...&to=...` требует `analytics.export`. Оба используют `budget.view` для раскрытия финансов. 403 без права, 422 при некорректном или инвертированном периоде.

## Бизнес-логика

Обработанным считается обращение в статусе `completed` или `rejected`; выполненной — задача `completed`. Время и бюджет суммируются по записям задач, попавшим в период. Excel отражает только те данные, которые видит вызывающий пользователь.

## Зависимости

TASK-005: данные; TASK-006: процессы обращений/задач; TASK-002: права.

## Критерии готовности

Автотесты проверяют расчёт каждого показателя, фильтр периода, скрытие бюджета и содержимое сформированного XLSX.
