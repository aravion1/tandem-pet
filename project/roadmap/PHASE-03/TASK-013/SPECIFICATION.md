# ID задачи: TASK-013

## Название задачи

Интерфейс аналитики и Excel-экспорта.

## Исполнитель

Frontend

## Полное описание

Создать mobile-first экран аналитики с выбором периода, отображением утверждённых показателей и действием выгрузки Excel.

## Контракты данных

Используется `AnalyticsReport` TASK-012. Если `budget` равно `null`, финансовый блок и финансовые колонки не отображаются.

## Эндпоинты

Потребляются `GET /api/analytics` и `GET /api/analytics/export` из TASK-012; новых нет.

## Бизнес-логика

Кнопка экспорта отображается только при `analytics.export`. Диапазон дат валидируется до запроса; ошибка API отображается без потери выбранных дат. Пользователь без `budget.view` не получает намёков на значения бюджета.

## Зависимости

TASK-012: API отчётов.

## Критерии готовности

UI-тесты проверяют выбор периода, показ показателей, скрытие бюджета и корректную загрузку Excel по праву.
