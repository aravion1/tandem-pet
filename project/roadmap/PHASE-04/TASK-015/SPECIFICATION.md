# ID задачи: TASK-015

## Название задачи

Сквозная приёмочная проверка пользовательских сценариев MVP.

## Исполнитель

Frontend

## Полное описание

Подготовить запускаемые сквозные UI-тесты мобильного веб-интерфейса, покрывающие критерии приёмки MVP и взаимодействие с готовым API. Исправления frontend-дефектов, найденных в этих сценариях, входят в задачу; дефекты API передаются в задачи-владельцы.

## Контракты данных

Используются контракты TASK-002, TASK-006, TASK-008, TASK-010 и TASK-012. Тестовые данные создаются через поддерживаемые API/фикстуры, без обхода авторизации.

## Эндпоинты

Потребляются существующие API указанных задач; новых нет.

## Бизнес-логика

Сценарии: импорт и активация; недоступность личного обращения постороннему; преобразование обращения и история; закрытие задачи только `tasks.close`; приватный чат без доступа правления; публикация; аналитика/Excel; скрытие действий по правам. Проверить отображение критических ошибок и мобильную ширину.

## Зависимости

TASK-003, TASK-007, TASK-009, TASK-011, TASK-013: интерфейсы; TASK-002, TASK-006, TASK-008, TASK-010, TASK-012, TASK-014: готовые серверные сценарии.

## Критерии готовности

Сквозной набор автоматически запускается и проходит; все десять критериев приёмки из FULLBUSINESS.md имеют минимум один тест; критические и блокирующие дефекты отсутствуют.
