# ID задачи: TASK-009

## Название задачи

Интерфейс обсуждений.

## Исполнитель

Frontend

## Полное описание

Реализовать списки обсуждений, создание публичного/приватного чата, приглашение участников, чат сообщений с вложениями и лайками, отображение вердикта и закрытого состояния.

## Контракты данных

Используются `Discussion`, `Message` и операции TASK-008. UI не показывает сообщения или метаданные приватного чата при 403.

## Эндпоинты

Потребляются эндпоинты TASK-008; новых нет.

## Бизнес-логика

Создатель может приглашать в приватный чат и закрывать его. Действие «Вердикт и закрыть» доступно только участнику с `discussions.moderate`. После `closed` поле отправки и кнопки действий отключены, история остаётся видна участникам.

## Зависимости

TASK-008: API обсуждений.

## Критерии готовности

UI-тесты покрывают создание обоих типов, приглашение, лайк, закрытие автором, вердикт модератором и недоступность отправки после закрытия.
