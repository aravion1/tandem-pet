# ID задачи: TASK-011

## Название задачи

Интерфейс новостей и инфо-бордов.

## Исполнитель

Frontend

## Полное описание

Создать пользовательские ленты/страницы опубликованных новостей и инфо-бордов, а также формы создания, редактирования, публикации и снятия с публикации для уполномоченных ролей.

## Контракты данных

Используется `Publication` TASK-010. Инфо-борд визуализируется как board, page или banner в соответствии с `presentation_format`.

## Эндпоинты

Потребляются эндпоинты TASK-010; новых нет.

## Бизнес-логика

Обычный житель видит только опубликованное. Управляющие формы и кнопки скрыты без права. Файлы добавляются без клиентских ограничений формата и размера; серверные ошибки отображаются пользователю.

## Зависимости

TASK-010: API публикаций.

## Критерии готовности

UI-тесты подтверждают отображение публикаций, три формата инфо-борда, создание черновика, публикацию и запрет управления без прав.
