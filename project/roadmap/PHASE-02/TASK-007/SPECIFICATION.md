# ID задачи: TASK-007

## Название задачи

Интерфейс обращений и задач.

## Исполнитель

Frontend

## Полное описание

Создать mobile-first списки, фильтры, карточки и формы создания/ведения обращений и задач, включая комментарии, вложения, историю, назначения, сроки, приоритеты, время и бюджет.

## Контракты данных

Используются `WorkItem` и операции TASK-006. Фильтры: `kind,status,priority,assignee,created_by,period`; изображения и файлы отображаются по метаданным вложения без редактирования.

## Эндпоинты

Потребляются эндпоинты TASK-006; новых нет.

## Бизнес-логика

Форма обращения предлагает публичную/личную видимость и адресата для личного. Доступные статусные действия рассчитываются по правам и текущему статусу. Отмена показывается автору только в очереди. Финальное «Выполнено» задачи показывается только с `tasks.close`.

## Зависимости

TASK-006: API и статусы.

## Критерии готовности

UI-тесты проверяют создание личного обращения, запреты отмены, конвертацию, историю и скрытие действий без прав; интерфейс работоспособен на мобильной ширине.
