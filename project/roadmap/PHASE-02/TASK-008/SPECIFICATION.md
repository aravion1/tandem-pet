# ID задачи: TASK-008

## Название задачи

API публичных и приватных обсуждений.

## Исполнитель

Backend

## Полное описание

Реализовать создание, участие, приглашения, сообщения, лайки, назначение вердикта и закрытие обсуждений с жёстной проверкой приватности.

## Контракты данных

`Discussion {id,title,visibility,status,author_id,members,verdict}`; `Message {id,discussion_id,author_id,body,attachments,created_at,likes_count}`. Статусы: `open`, `closed`; видимость: `public`, `private`.

## Эндпоинты

`GET/POST /api/discussions`; `GET/PATCH /api/discussions/{id}`; `POST /api/discussions/{id}/members {user_ids}`; `POST /api/discussions/{id}/messages`; `POST /api/messages/{id}/like`; `POST /api/discussions/{id}/verdict {message_id}`; `POST /api/discussions/{id}/close`. Ошибки: 403 для неучастника приватного чата, 409 для записи в закрытый чат или повторного лайка, 422 для некорректных участников.

## Бизнес-логика

Любой пользователь создаёт обсуждение; создатель приватного приглашает участников. Правление не получает обходного доступа. Автор закрывает любое своё обсуждение. Участник с `discussions.moderate` может назначить вердикт и закрыть обсуждение. Сообщения не редактируются и не удаляются.

## Зависимости

TASK-002: аутентификация; TASK-004: вложения; TASK-005: схема.

## Критерии готовности

Тесты подтверждают невозможность чтения приватного обсуждения неприглашённым, запрет записи после закрытия, один лайк пользователя и смену вердикта с историей.
