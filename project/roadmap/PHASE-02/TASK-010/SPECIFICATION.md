# ID задачи: TASK-010

## Название задачи

API новостей и инфо-бордов.

## Исполнитель

Backend

## Полное описание

Реализовать публикационный API для новостей и инфо-бордов, доступный по соответствующим правам, с жизненным циклом черновика и публикации, вложениями и аудитом.

## Контракты данных

`Publication {id,type,title,body,presentation_format,author_id,status,created_at,published_at,updated_at,attachments}`. `type`: `news|infoboard`; `status`: `draft|published|unpublished`. `presentation_format` обязателен только для инфо-борда и принимает `board|page|banner`.

## Эндпоинты

`GET /api/news`, `GET /api/news/{id}`, `POST/PATCH /api/news`, `POST /api/news/{id}/publish`, `POST /api/news/{id}/unpublish`; аналогичные пути `/api/infoboards`. Управление требует `news.manage` или `infoboards.manage`; публичное чтение — авторизованному жителю. 403, 404, 409, 422.

## Бизнес-логика

Публикация/снятие и изменения фиксируются в аудите. После публикации создаётся событие уведомления жителей. Только опубликованные записи показываются обычным пользователям; редактирование не удаляет аудит.

## Зависимости

TASK-002: права; TASK-004: файлы; TASK-005: таблицы публикаций.

## Критерии готовности

Тесты подтверждают права, видимость черновиков, смену статуса, аудит и создание события уведомления.
